# 🐍 AIML – Python Practice

My Python coursework and practice from the AIML track: assignments that go from basics to object-oriented programming, plus a small OOP chatroom simulation.

> Most exercises are kept as commented-out blocks inside each file – uncomment one to run it.

## 📚 What's Inside

| File | Topics |
|------|--------|
| `assignment_1.py` | Input/output, arithmetic operators, type conversion, operator precedence, swapping, °C → °F, area of a circle |
| `py_part2.py` | Conditionals (`if/elif/else`), simple login check, multiples, `match`-case |
| `assignment_2.py` | Tax slabs, even numbers in a range, printing/counting digits, functions |
| `py-3.py` | Strings (indexing, slicing, `format`), lists, tuples, dictionaries |
| `ass_3.py` | Palindrome check, list sum/merge/sort, splitting tuples into odd/even, a dictionary-based student marks manager |
| `py-4.py` | Classes – class vs instance attributes, `@classmethod`, `@staticmethod` (laptop database & discount example) |
| `ASS4.PY` | OOP – encapsulation (bank account, student with validated private fields), book reviews, inheritance (shapes), abstract classes (vehicles) |
| `chatbot.py` | **Chatroom simulation** – `Message`, `User` and `ChatRoom` classes: join/leave rooms, broadcast messages, chat history (runnable demo) |
| `PY-1.PY` | Placeholder (empty) |

## 🛠️ Tech Stack

- Python 3 (standard library only – no external packages)

## 🚀 Run Locally

```bash
git clone https://github.com/shivamani-code/AIML.git
cd AIML
python chatbot.py
```

For the assignment files, uncomment the exercise you want and run the file with `python <file>.py`.
